# 판타지악 v2.0.5 — 심화 전직 재검증 + 동료 욕구 패치

## 1. 2차 심화 전직 최종 재검증

현재 2차 심화 전직은 총 23종이다.

- 전사: 대검전사 / 창술사 / 검술사 / 쌍검술사
- 궁수: 배틀슈터 / 스나이퍼 / 실프 / 아처
- 도적: 듀얼블레이드 / 암살자 / 씨프
- 성직자: 사제 / 수도사 / 힐러 / 홀리나이트
- 마법사: 아케인 메이지 / 마법검사 / 위자드 / 크로우
- 무희: 서큐버스 / 검무희 / 댄서 / 변기

모든 심화 전직에 다음을 연결했다.

- 고유 패시브 1종
- 전용 액티브 3종
- 심화 전직 자체 스탯 보너스의 실제 전투 반영
- 고유 패시브 스탯 보너스의 실제 전투 반영
- 전직 완료 즉시 전용 액티브 3종 습득
- 전용 액티브의 스킬 성장 상태 자동 등록

### 재검증에서 추가 수정한 부분

- 마법검사는 전사 계열에서 완전히 제거하고 마법사 계열에만 배치했다.
- 위자드의 심화 보너스가 물리 관통으로 지정되어 있던 값을 마법 관통으로 수정했다.
- 사제 `정화의 빛`은 실제 아군 1명을 대상으로 해로운 상태를 정화하고 보호막/마법 방어를 부여하도록 수정했다.
- 힐러 `공동 기도`는 실제 아군 전체 회복 + 재생 효과로 수정했다.
- 힐러 `생명 수호`는 실제 아군 1명에게 강한 보호막과 방어/마법 방어 상승을 부여하도록 수정했다.
- 심화 전직 화면에 노출되던 내부 능력치 키는 한국어 표기명을 사용한다.
- 전직 스킬 표시명에 붙어 있던 영문 병기를 제거했다.

## 2. 변기 심화 전직 표시 규칙

`변기`의 전용 액티브는 내부적으로 3개의 고정 ID를 유지하지만 사용자 화면에서는 스킬 이름과 설명을 비워 둔다.

- 내부 ID는 세이브/전투/효과 연결용으로만 사용한다.
- 클래스 화면은 내부 ID를 대체 이름으로 표시하지 않는다.
- 전투 화면에서도 이름이 없는 기술은 내부 ID를 노출하지 않는다.
- 기술 효과 수치와 실제 버프 처리만 엔진에 존재한다.

## 3. 영입 가능 동료 성별 규칙

- 영입 가능한 주요 인물은 모두 남성으로 정규화한다.
- 신규 영입 시 `gender` 내부 필드는 `남성` 표시값으로 생성한다.
- 기존 세이브에서 이미 영입된 동료도 로드 시 남성으로 정규화한다.
- 영입 동료의 신체적 나이는 최소 18세로 정규화한다.
- 현재 주요 인물 51명 중 영입 가능 인물은 50명이며 50명 전부 남성이다.

## 4. 동료 욕구 상태

동료 데이터에 별도 욕구 상태를 추가한다.

- UI 표기 `성욕`: 0~100
- UI 표기 `배설 욕구(소변)`: 0~100
- 코드 내부 필드/이벤트 키는 영어 식별자를 사용하되 사용자 UI에 그대로 노출하지 않는다.

### 성욕

- 성인 플레이어의 정상 스토리 로그가 확정될 때 영입 동료마다 기본 +3.
- 30 / 50 / 70 / 100을 처음 위로 통과하면 해당 단계의 장면 큐를 1회 생성한다.
- 수치가 해당 임계값 아래로 내려간 뒤 다시 통과하면 다시 발생할 수 있다.
- 플레이어 신체적 나이가 18세 미만이면 동료 성욕 자동 증가와 관련 장면 큐를 생성하지 않는다.

### 배설 욕구(소변)

- 실제 게임 시간이 흐를 때 증가한다.
- 기본 증가율은 기존 방광 시간 엔진의 생산률을 공유한다.
- 30 / 50 / 70 / 100 통과 시 단계별 장면 큐를 생성한다.
- 100 도달 시 기본 엔진은 사생활이 확보된 곳에서 정상적으로 용변을 해결한 것으로 처리하고 수치를 0으로 되돌린다.

## 5. 장면 큐와 사용자 작성 참조

`src/data/companions/companionNeedReferences.ts`에 단계별 장면 참고자료가 존재한다.

각 단계는 다음 두 층으로 나뉜다.

1. `baseReference`: 게임 기본 참고자료
2. `customReference`: 사용자 작성 참고자료

`customReference`는 기본값이 빈 문자열이며, 사용자가 실제 내용을 작성한 경우에만 Gemini 프롬프트에 포함된다. 빈 값은 절대 전달하지 않는다.

70/100 단계에서는 활성 파티에 다른 동료가 존재할 경우 임의의 보조 동료 ID를 함께 전달할 수 있다. 기본 참고자료에서는 상황을 눈치채거나 돕는 정도로만 사용한다.

장면 큐는 1회성이다. 이전 GM 로그에서 참조한 큐는 다음 상태 적용 시 소비되고, 이후 새로 넘어간 임계 단계만 다음 로그에 전달된다.

## 6. UI 표기 규칙

새로 추가/수정한 시스템에서 내부 영문 키를 화면에 직접 표시하지 않는다.

- `desire` → 성욕
- `urinationUrge` → 배설 욕구(소변)
- 직업 내부 ID → 전사 / 궁수 / 도적 / 성직자 / 마법사 / 무희
- 종족 내부 ID → 기존 한국어 표기 함수 사용
- `physicalAttack` 등 전투 스탯 내부 키 → 한국어 능력치명
- 기술 자원 → 전투 자원
- 재사용 대기 수치 → 재사용 N턴

## 7. 세이브 호환

기존 v2.0.5 세이브를 불러올 때:

- `needs`가 없는 동료에게 기본 욕구 상태를 생성한다.
- `companionNeedQueue`가 없으면 빈 배열을 생성한다.
- 기존 동료의 전직/장비/직업/신뢰/유대 상태는 보존한다.
- 영입 동료 성별과 성인 연령 규칙을 정규화한다.
- 구 세이브의 기존 마법검사 전직 ID는 전투에서 계속 읽을 수 있도록 조회 호환을 유지한다.
