# 판타지악 v1.0 — 전직/스킬트리 + 세계/운명 + Hex 월드맵 패치

## 1. 플레이어/종족
- 플레이어블 캐릭터 성별: 여성 고정.
- 수인(여우/고양이/개/늑대/새): 세계관상 전원 여성.
- 신규 플레이어 종족: 설인(YETI), 인어족(MERFOLK).
- 인어족은 수인계에서 갈라진 설정이지만 게임 타입은 독립 종족.

## 2. 전직/스킬트리
- Lv.1~4: 일반 공격/방어 중심.
- Lv.5: 기본 전직 퀘스트 → 6기본직 전직 UI.
- Lv.20: 심화 전직 퀘스트 → 현재 기본직의 심화 계열 UI.
- 가지형 스킬트리: 좌표+연결선 기반.
- 액티브: 기본/심화/유일, 유일 액티브 직업당 4종(총 24).
- 패시브: 기본/심화/유일.
- 레벨업/엘리트/보스용 패시브 해방석 보상 루프.
- 기본 패시브 중복, 심화 조합식/합성, 유일 패시브 잔재+pity 구조.
- 엘리트 최초 처치 시 현재 직업의 미획득 심화 패시브 조합식 후보 해방.
- `REGIONAL_BOSS` trait 보스는 현재 직업 유일 액티브 후보 지급 구조 지원.

## 3. 운명/지역
- 캐릭터 생성 7단계: 기본정보 → 종족 → 외형 → 스탯 → 시작지역 → 운명 → 확정.
- 종족별 시작 지역 제한.
- 운명별 시작 장소/루피/아이템/특성/세계 플래그.
- 6지역: 그란디아, 세이레, 포레진, 산티맥, 프로스티, 스크로제.

## 4. Hex 지도
- 터치 드래그/pan.
- 두 손가락 pinch zoom.
- 마우스 휠 및 +/- zoom.
- Hex 선택 후 A* 경로 계산.
- 경로 모드: 최단/최속/안전.
- Hex 단위 실제 시간 경과.
- 각 Hex 진입 시 지역/지형/레이어 기반 사건/몬스터 판정.
- 중간 몬스터 조우 시 이동 중단 후 CTB 전투 연결.
- Fog of War / 발견 / 탐사 상태 저장.

## 5. 지도 레이어
- SURFACE: 지상.
- UNDERWATER: 해저.
- DEEP_SEA: 심해.
- SKY: 하늘/스크로제.
- CELESTIAL: 천공/스크로제.
- UNDERGROUND: 타입은 예약되어 있으나 **개발 중 / 진입 불가 / Hex 0개**.

## 6. 스크로제 항법
- 하늘 전체의 약 1/5만 부유 육지.
- 하늘 지도/나침반/망원경 3종으로 미지의 하늘 항법 해금.
- 천공 지도/나침반/망원경 + 허가증/상승기류 등으로 천공 항법.
- 프로스티 중앙 정상은 지상→하늘 자연 통로.
- 아벨라는 dayCount에 따라 천공 Hex 좌표가 이동.
- 에도와는 천공 특수 거점.

## 7. 세이브 마이그레이션
- 구 세이브에 skillProgression/fate/worldMap이 없어도 자동 기본값 주입.
- 플레이어 profile.gender는 로드 시 여성으로 정규화.
- 신규 지도/스킬 상태는 PlayerState에 영구 저장.

## 8. 미완성으로 의도적으로 남긴 콘텐츠
- 지하 지도/지하 콘텐츠 전부: 개발 중.
- 지역 보스 실데이터: 사용자 추후 설정용. 엔진 훅만 존재.
- 6지역의 정확한 대륙 외곽/지리적 윤곽: 현재 기술적 Hex 배치. 추후 좌표만 교체 가능.
- 전직 퀘스트의 구체적 스토리/NPC: 시스템 퀘스트 슬롯만 구현.
