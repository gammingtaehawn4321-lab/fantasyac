# 장비/생활직업/제작 2.0 통합 패치

- 1차 메뉴: 상태 → 성장 → 가방 → 제작 → 모험 → 동료
- 장비: 일반/엘리트/레전더리, T1~T12, 6단계 품질, 확장형 수식어/효과/획득/몬스터 출처/세트 구조
- 갑옷: 천옷(CLOTH) / 경갑(LIGHT) / 중갑(HEAVY) 유지
- 세트: 엘리트 이상을 위한 2/3/4피스 데이터 기반 구조. 임시 미래 몬스터 ID를 사용해 몬스터를 나중에 역설계 가능
- 생활직업: 대장장이/가죽 세공인/연금술사 활성, Lv.1~60, 입문~거장, 스킬포인트 기반. 나머지는 준비 중
- 제작: 생활직업 화면에서 분리된 독립 UI. 복수 생활직업 요구 조건 지원
- 미래 확장: 중량/경량 갑옷 파츠, 인챈트, 추가 생활직업, 전투 Trigger/Condition/Effect 연결 자리 확보
- server.ts는 수정하지 않음

참고: 현재 프로젝트 의존성이 설치되지 않은 환경이라 전체 tsc는 React/Express 등 모듈 미탐색 오류로 완료되지 않았으며, 출력에서 이번 패치 고유 타입 오류는 확인되지 않았습니다.
