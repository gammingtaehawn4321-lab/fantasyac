# 몬스터·전리품·패배 후 인카운터 패치 가이드

## 범위
- 몬스터 18 → 90종 (5배)
- 지역별 15종 균등 분배
- Race: HUMANOID / ABERRANT + 세부 타입
- Hex 지형/섹터 기반 출현
- 몬스터별 제작재료 + 실제 장비 DB 드랍 후보
- 처치한 적 단위 EXP/루피/아이템 결산
- 승리/도주/패배 결과 화면에 EXP와 아이템 수량 표시
- 일반전 패배 시 확률적 후속 인카운터
- 사망 결과일 경우 전투 외 부활의 물약
- 엘리트/보스는 패배 후 건너뛰기/부활 물약 금지

## 패배 후 인카운터 확률
### 인간형에게 패배
- 팔려간 포로 26%
- 납치 22%
- 강탈 후 방치 18%
- 구조 10%
- 사망 24%

### 이형에게 패배
- 몬스터 소굴 34%
- 납치 18%
- 강탈 후 방치 12%
- 구조 6%
- 사망 30%

패배 인카운터는 세계관 사건으로 비그래픽하게 처리된다. 전투 결과는 항상 패배로 기록되며, 이미 처치한 적의 보상은 유지된다.

## 부활의 물약
- 전투 중 부활 아님
- 일반전에서 후속 인카운터가 사망으로 결정되었을 때만 사용 가능
- 사용 후 해당 전투는 패배 처리 그대로 유지
- 전투를 포기하고 전장에서 생환: HP 35%, 정신력 최소 25%, 게임 시간 +60분
- 엘리트/보스/지역보스가 포함된 전투에서는 사용 불가

## 사용자 수정 포인트
1. 몬스터 추가/삭제: `src/data/world/monsterData.ts`
2. 드랍 확률·EXP·루피·장비후보: `src/data/world/monsterLootSystem.ts`
3. 지역별 섹터 인카운터: `src/data/world/sectorEncounters.ts`
4. 패배 사건 확률/결과: `src/data/world/defeatEncounterSystem.ts`
5. 전투 종료 결산: `src/combat/battleEngine.ts` + `src/App.tsx`
