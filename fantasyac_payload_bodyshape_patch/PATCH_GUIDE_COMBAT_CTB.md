# 판타지악 전투 엔진 CTB / COST / 속성 패치

## 이번 패치 범위
전투 UI 전면 개편 전, 실제 전투 계산과 턴 구조를 먼저 고정하는 엔진 패치다. 삽화/PNG/신규 전투 이펙트는 포함하지 않는다.

## 1. CTB 행동 엔진
- 고전적인 1라운드 1행동 구조를 제거하고 순차 CTB 방식으로 전환.
- `ACTION_THRESHOLD = 1000`.
- 각 Actor의 `actionGauge`가 최종 속도(`effectiveSpeed`)에 따라 증가.
- 속도가 높은 Actor는 장기적으로 실제 행동 횟수가 증가.
- 행동 중 게이지가 실시간으로 오르지 않으며, 행동이 완전히 끝난 뒤 다음 Actor를 계산하는 순차식 CTB.
- 동률은 `최종 속도 → 게이지 초과량 → 전투 시작 시 고정 stableTieBreaker` 순서로 판정.
- 매 행동마다 랜덤 선공 보정은 사용하지 않음.

## 2. Action Delay / Timeline
- 스킬에 `actionDelay` 지원.
- 기본값 1.00, 빠른 기술 0.75, 방어 0.80, 아이템 계열 0.90, 강한 기술 1.20, 대형 기술 1.50 등을 적용할 수 있음.
- 행동 후 `1000 × actionDelay`만큼 행동 게이지를 소비.
- 동일 Actor 중복을 허용하는 향후 12회 행동 Timeline 계산 함수 추가.
- 스킬 선택 시 실제 상태를 변경하지 않고 Action Delay를 반영한 Timeline 미리보기 함수 추가.
- 속도 버프/둔화가 걸리면 다음 Timeline 계산부터 즉시 반영.

## 3. COST
- 전투 스킬 핵심 자원을 MP에서 COST로 전환.
- 전투 시작 COST 10.
- 기본 최대 COST 30.
- 자신의 행동 기회 시작 시 기본 +5.
- 장비/파생 스탯으로 `maxCost`, `costRegen` 변경 가능.
- 기존 스킬 `mpCost` 값은 밸런스를 임의 변경하지 않고 동일한 `cost` 값으로 이관했고, `mpCost`는 구 데이터 호환용으로 유지.
- 장비의 스킬 COST 감소 보정 지원.

## 4. 쿨타임
- 런타임 `skillCooldowns` 추가.
- 스킬 사용 시 실제 쿨타임 등록.
- 사용자 자신의 행동 기회 시작 시 1 감소.
- COST 부족/쿨타임 중 행동은 실행되지 않으며 행동 기회도 소비하지 않음.

## 5. 상태이상 턴 기준
- 독 / 출혈 / 화상 / 재생: 대상 자신의 행동 시작 시 발동.
- 버프 / 디버프 지속시간: 대상 자신의 행동 종료 시 1 감소.
- 자기 행동 도중 자신에게 새로 건 버프는 같은 행동 종료 시 즉시 1턴 줄어들지 않도록 처리.
- 기절/매혹/흐트러짐은 해당 Actor 행동 기회를 실제로 막음.

## 6. 속성 시스템 실제 연결
현재 스킬 데이터에서 실제로 확인되는 속성을 우선 연결:
- NEUTRAL
- FIRE
- ICE
- LIGHTNING
- HOLY
- DARK
- ARCANE
- PSYCHIC
- POISON

속성 피해식:
- 대상 `elementResistances[element]` 양수 = 저항, 음수 = 약점.
- 공격자 `elementalPenetration`으로 속성 저항 관통.
- 공격자 `elementDamageBonuses[element]`으로 해당 속성 최종 피해 증가.
- 저항은 현재 -100% ~ +80% 범위로 클램프.
- 과거에 확정된 별도 상성표가 현재 기준 ZIP에서 확인되지 않아 임의의 불/물/번개 상성표는 새로 만들지 않았음. 몬스터/장비 데이터의 저항·약점 값으로 즉시 운용 가능.
- 장비 정의에도 `elementResistances`, `elementDamageBonuses`를 추가하고 BattleActor 생성 시 실제 합산되도록 연결.

## 7. 물리/마법 관통 수정
기존에는 마법 피해 계산에도 `physicalPenetration`이 사용되는 오류가 있었음.
- 물리 피해 → `physicalPenetration`
- 마법 피해 → `magicPenetration`
- 속성 저항 → `elementalPenetration`
으로 분리.

## 8. 치명타
- `criticalChance`와 `criticalDamage`는 실제 최종 피해식에 적용됨을 재검증.
- 장비의 치명타 확률/피해 보너스도 `calculateCombatStats()`를 거쳐 실제 BattleActor에 반영.
- 치명타 확률/피해 상한을 전투 상수로 통합:
  - 일반 치명타 확률 상한 85%
  - 치명타 피해 배율 상한 3.0x
- 확정 치명타 스킬은 확률 상한과 별개로 확정 발동.

## 9. 스킬 실행 보완
- 액티브 스킬 40개 모두 새 COST 실행 경로로 진입하도록 확인.
- 기존 전용 처리가 거의 없어서 비피해 버프/방어 스킬이 기본 피해 처리로 빠질 수 있던 문제 수정.
- 방어, 회복, 보호막, 명중/회피/공격 버프, 기절, 출혈, 독, 화상, 둔화, 매혹, 공포 등 현재 스킬 설명에 필요한 핵심 효과를 실제 처리.
- 흐트러짐 피해 및 발동도 실제 Actor 상태에 반영.

## 10. 동료/적 AI와 도주
- 동료/적 AI가 MP가 아니라 실제 COST와 쿨타임으로 사용 가능 스킬을 판정.
- 동료는 현재 기본 AI 조작 유지. 수동 전환 UI는 다음 전면 개편 때 연결 가능하도록 Actor 필드를 준비.
- 도주 실패 시 플레이어 행동 1회 소비 후 CTB 계속 진행.
- 도주율은 아군 평균 최종 속도와 적 평균 최종 속도를 반영.
- `canEscape=false` 전투는 행동을 소비하지 않고 도주 불가 처리.

## 11. 기존 UI 임시 호환
전면 UI 개편은 아직 하지 않음.
다만 새 엔진을 현재 화면에서도 시험할 수 있도록 기존 CombatScreen의 전투 자원 표시/사용 가능 판정만 최소한으로 MP → COST/CD 기준에 맞춤.
