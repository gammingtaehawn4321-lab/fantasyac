# 판타지악 v2.0.5 — 동료 욕구 순환/전투력 가속 패치

## 1. 이벤트 발생 후 즉시 초기화
- 동료의 `성욕` 또는 `배설 욕구(소변)` 특수 인카운터가 실제 큐에 생성되는 순간 해당 수치는 0으로 초기화된다.
- 해당 욕구의 임계치 판정 기록도 함께 초기화된다.
- 따라서 같은 동료가 다시 욕구를 누적하면 동일 단계의 이벤트가 다시 발생할 수 있다.

## 2. 임계 단계 유지
임계치는 30 / 50 / 70 / 100을 유지한다.

이벤트 발생 즉시 0으로 초기화하면 30 단계가 항상 발생할 경우 상위 단계가 영구적으로 봉쇄되므로, 임계 단계별 실제 발생 판정을 둔다.

- 30: 25%
- 50: 45%
- 70: 70%
- 100: 100% (확정)

해당 단계 판정에 실패하면 욕구 수치는 그대로 유지되어 다음 단계까지 누적된다. 이벤트가 발생한 단계에서는 즉시 0으로 초기화된다.

## 3. 강한 동료의 욕구 증가 가속
동료마다 내부적으로 욕구 증가 배율을 계산한다.

계산에 사용하는 요소:
- 레벨
- 현재 6능력치 총합
- 심화 전직 단계

배율 범위:
- 최소 1.0배
- 최대 3.0배

따라서 레벨과 능력치가 높고 심화 전직 단계가 높은 동료일수록 `성욕`과 `배설 욕구(소변)`이 더 빠르게 증가한다.

기본 증가량:
- 성욕: 스토리 로그 1회당 +3 × 동료 전투력 배율
- 배설 욕구(소변): 분당 +0.035 × 동료 전투력 배율

## 4. UI 표기
내부 코드는 영문 식별자를 유지하지만, 사용자 UI에는 기존과 동일하게 한국어 표기만 사용한다.
- 성욕
- 배설 욕구(소변)

이번 패치에서 새 내부 확률/배율 키는 UI에 표시하지 않는다.
