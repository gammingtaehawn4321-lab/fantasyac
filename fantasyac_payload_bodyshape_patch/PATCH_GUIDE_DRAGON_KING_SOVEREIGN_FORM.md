# 판타지악 v2.0.5 — 용왕 / 용제 현현 패치

## 전직 구조
- 용족 Lv.5 기본 전직 표기: 『용왕』.
- 내부 레거시 class id `DRAGON_EMPEROR`는 구 세이브 호환을 위해 유지하며 UI에는 노출하지 않는다.
- Lv.20 용족 심화 전직 4종:
  - 업화의 비룡 — 불 / 공격 누적
  - 천수의 사룡 — 풀·생명 / 회복 누적
  - 뇌명의 천룡 — 번개 / 추가 공격·치명타 누적
  - 서리의 한룡 — 얼음 / 피격·보호막 누적

## 공통 『용제』 현현
- 각 계통 전용 자원 0~100.
- 100 도달 즉시 자동 현현, 자원 0으로 소비.
- 현현 지속: 자기 행동 4회.
- 현현 보정: 공격/마법 공격 +45%, 방어 +40%, 명중 +25, 회피 +20, 치명타 +20, 행동 속도 +35%.
- 최종 받는 피해 ×0.65.
- 계통 전용 스킬은 현현 중 피해 계수 ×1.35 및 고유 부가효과 강화.
- 종료 직후 행동 게이지 -500 추가.
- 『용맥 탈진』: 자기 행동 3회 동안 행동 속도 -45%, 받는 피해 +35%.

## 자원 획득
- 업화의 비룡 『불꽃』: 일반 공격계 행동 +10, 화염 공격계 행동 +18, 용로심 +28.
- 천수의 사룡 『천수』: 회복 스킬과 실제 회복량을 합산해 축적.
- 뇌명의 천룡 『뇌명』: 치명타 +18, 추가 뇌격 +14(추가 뇌격 치명 시 추가 +8). 평상시 추가 뇌격 38%, 현현 중 100%.
- 서리의 한룡 『서리』: 받은 실제 피해 비율에 따라 +8~30, 자기 보호막 +24 이상, 광역 빙성 +32.

## UI
- 전직 화면: 『용왕』 → 네 심화 계통.
- 전투 카드: 내부 resource key 대신 『불꽃 / 천수 / 뇌명 / 서리』를 0~100으로 표시.
- 현현 중에는 자원 바가 『용제 현현 · 현현 중』으로 변경.
- 내부 영어 class/trait/resource 키는 UI에 노출하지 않는다.
