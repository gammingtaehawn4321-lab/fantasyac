# 판타지악 v2.0.5 패치

## 범위
이번 패치는 펫/동반자 개편 직전의 마감 패치입니다. 기존 1차 UI 메뉴 구조와 펫 시스템은 변경하지 않습니다.

## 주요 인물 고유 퀘스트
- 2.0 신규 주요 인물 45명 중 `villainous: true`가 아닌 31명에게 CHARACTER 퀘스트 1개씩 추가.
- 각 퀘스트는 인물의 직업·지역·성격과 기존 생활/이동/전투 시스템을 연결해 진행됩니다.
- `villainous: true` 14명은 `customQuestIds: []` 그대로 유지.
- 기존 `user_encounter_slot_01~05` 등 사용자용 빈 퀘스트/인카운터 슬롯은 수정하지 않음.
- 기존 2.0 세이브에 저장된 빈 `customQuestIds`는 로드/정규화 시 2.0.5 공식 퀘스트 연결만 보강합니다.

## 오류 수정
- 동료 전투 파티 상한을 UI와 엔진 모두 최대 4명으로 통일.
- 여행 도중 몬스터 조우로 경로가 끊기면 실제 이동한 Hex만 이동거리로 기록.
- 비행정 연료도 예정 경로 전체가 아니라 실제 이동한 SKY/CELESTIAL 구간만 차감.
- 비행정 연료가 가득 찬 상태에서는 연료전지를 소모하지 않음.
- 역참 특수 인카운터 시작 시 정식 `ENCOUNTER_STARTED` 이벤트를 사용.
- 진행 중 인카운터가 실제로 해결/실패했을 때 Gemini가 `encounterAction`을 반환하고 엔진이 `ENCOUNTER_RESOLVED` / `ENCOUNTER_FAILED`를 처리하도록 생명주기를 연결.

## USER_TODO 규칙
- 기존 USER_TODO 빈 슬롯은 그대로 유지.
- 비어 있거나 기본 플레이스홀더인 참조는 Gemini 참고자료로 취급하지 않는 기존 규칙 유지.
- 이번 패치에서 실제 내용을 채운 31명 캐릭터 퀘스트만 정식 데이터로 참조됩니다.
