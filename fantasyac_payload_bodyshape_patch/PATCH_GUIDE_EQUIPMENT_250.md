# 판타지악 장비 250종 확장 패치

## 범위
- 기존 장비 31개를 삭제/대체하지 않고 유지.
- 신규 장비 219개 추가, 전체 `EQUIPMENT_DATABASE`를 정확히 250개로 확장.
- 신규 24세트 × 5부위 = 120개 세트 장비.
- 신규 단품 99개 = 주무기 45 + 보조장비 12 + 장신구 30 + 단품 방어구 12.

## 세트 시스템
- 신규 세트는 전사/궁수/도적/성직자/무희/마법사 각 4세트(T3/T6/T9/T12).
- 각 세트는 HEAD/CHEST/LEGS/GLOVES/BOOTS 5개 파츠.
- 2/3/4피스 보너스가 누적 활성화.
- `STAT_MODIFIER`, `ELEMENT_DAMAGE_BONUS`, `ELEMENT_RESISTANCE`, `TRAIT`를 세트 효과 해결기가 실제 전투 수치로 변환할 수 있도록 구현.
- `resolveEquipmentSetEffects()`가 현재 장착 장비를 검사해 세트 효과를 합산.
- `battleEngine.ts`에서 세트 효과를 실제 BattleActor의 공격/방어/속도/COST/관통/치명타/속성 보정 등에 반영.

## 장비 UI
- 장비 슬롯/인벤토리 카드에 TIER / 급 / 품질 표시.
- 세트 장비 상세에 세트명, 현재 장착 수, 2/3/4세트 옵션 표시.
- 활성화된 세트 옵션은 체크 표시와 활성 색으로 구분.
- 장비 화면 종합 전투 수치는 이제 실제 BattleActor 계산을 사용하여 장비 및 세트 효과를 반영.

## 자원 옵션 보완
기존 장비 데이터에는 `maxHp`, `maxMp`, `maxSanity`가 있었지만 BattleActor의 실제 최대 자원에 연결되지 않던 문제가 있었다.
이번 패치에서 장비 및 세트의 최대 HP/MP/정신력 증가가 실제 전투 자원 최대치에 반영되도록 수정했다.

## 데이터 구조
신규 데이터는 `src/data/equipment/equipmentExpansionCatalog.ts`에 집중해 기존 수제 장비 DB를 과도하게 비대화하지 않는다.
`equipmentDatabase.ts`에서 생성 카탈로그를 병합하며, 기존 세이브의 장비 ID는 그대로 유지된다.

## 이미지
사용자 요청 전 이미지 생성 금지 방침을 유지했다. 신규 장비에는 별도의 PNG/삽화를 생성하거나 삽입하지 않았다.
