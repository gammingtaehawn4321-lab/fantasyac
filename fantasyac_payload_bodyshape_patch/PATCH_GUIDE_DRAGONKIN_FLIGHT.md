# 판타지악 v2.0.5 — 용족 천룡비행 추가 패치

## 신규 종족 패시브
- 이름: 『천룡비행』
- 내부 ID: `DRAGONKIN_SKYFLIGHT`
- 대상: 플레이어블 용족 전용

## 효과
- 하늘(SKY)과 천공(CELESTIAL)을 비행정 없이 직접 이동할 수 있습니다.
- 용족은 같은 좌표에 대응 레이어가 존재하면 지상↔하늘↔천공을 특정 승강장 없이 직접 오르내릴 수 있습니다.
- 직접 비행 시 비행정 연료를 소비하지 않습니다.
- 용족은 하늘/천공 미지 경로를 선천적 감각으로 탐색할 수 있어 항법 도구 3종을 강제하지 않습니다.
- 하늘/천공 이동 시간에 종족 이동 보정 0.72배가 적용됩니다.
- 월드맵 경로 UI에는 영어 내부 키 대신 `직접 비행`으로 표시됩니다.
- 용족 상태 UI에는 `천룡비행 · 하늘/천공 직접 비행`으로 표시됩니다.

- 패시브 정의: `src/data/raceData.ts`
- 레이어 진입/경로/연료 판정: `src/data/world/worldMapSystem.ts`
- 월드맵 표시: `src/components/WorldMapModal.tsx`
- 이동 로그: `src/App.tsx`
- 용족 상태 UI: `src/components/StatusModal.tsx`
