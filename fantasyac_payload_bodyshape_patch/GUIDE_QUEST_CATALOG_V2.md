# 가이드 퀘스트 v2.0

- **가이드 — 가방과 생활 재료** (guide_inventory): 생활 재료를 획득하고 인벤토리에서 용도와 수량을 확인합니다.
- **가이드 — 제작** (guide_crafting): 생활직업 제작을 한 번 수행합니다.
- **가이드 — 생활직업** (guide_profession): 생활직업을 성장시켜 전문 제작의 기초를 익힙니다.
- **가이드 — 장비** (guide_equipment): 획득한 장비를 실제 슬롯에 장착해 봅니다.
- **가이드 — 야영** (guide_camp): 야영지에서 휴식해 시간과 회복 시스템을 익힙니다.
- **가이드 — 육각 월드맵** (guide_world_map): 지도에서 다른 Hex로 이동하여 탐험과 시간 경과를 확인합니다.
- **가이드 — 장거리 이동 한도** (guide_travel_range): 여행 도구를 준비해 지상 한 번 이동 가능한 최대 Hex를 늘립니다.
- **가이드 — 역참 교통망** (guide_waystation): 역참에서 루피를 지불해 안전 노선을 한 번 이용합니다.
- **가이드 — 나만의 비행정** (guide_airship): 재료를 모아 비행정을 건조하고 하늘을 직접 비행합니다.
- **가이드 — 에테르 항해** (guide_airship_flight): 연료를 채우고 비행정으로 하늘 또는 천공을 한 번 이동합니다.
- **가이드 — 채집** (guide_gathering): 월드맵의 현재 Hex에서 생활 자원을 채집합니다.
- **가이드 — 주요 인물과 호감도** (guide_character): 주요 인물과 대화를 반복해 신뢰를 쌓는 법을 익힙니다.
- **가이드 — 동료 영입** (guide_recruitment): 충분한 신뢰를 쌓은 주요 인물을 동료로 영입합니다.
