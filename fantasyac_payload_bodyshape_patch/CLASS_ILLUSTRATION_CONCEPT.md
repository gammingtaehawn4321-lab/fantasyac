# 판타지악 — 종족 × 직업 전직 삽화 콘셉트 기준본

> 이 문서는 이미지 생성 지시서가 아니라, 실제 생성 전에 사용할 디자인 기준본이다. 현재 패치에서는 신규 이미지를 생성하지 않는다.

## 1. 레퍼런스에서 확정한 공통 화풍
- 세로형 전신 캐릭터 일러스트. 발끝까지 보이는 7~8등신 미형 판타지 애니메이션 스타일.
- 밝은 백색/극저채도 배경. 배경 풍경보다 캐릭터, 무기, 천 조각, 마력, 소환물, 광륜 등의 직업 상징을 우선한다.
- 얇고 섬세한 선화 + 부드러운 셀/회화 혼합 채색. 검은 외곽선을 지나치게 두껍게 사용하지 않는다.
- 캐릭터는 화면 높이의 약 82~90%. 정면 또는 3/4 시점.
- 한 장의 핵심은 ‘직업 실루엣’. 썸네일만 보고도 직업을 식별할 수 있어야 한다.
- 이미지 내부 텍스트 없음. 직업명/종족명/UI 문자를 삽입하지 않는다.
- 같은 직업의 종족별 그림은 카메라 높이와 핵심 무기 배치를 어느 정도 공유하되, 신체/문화/재질/장비 구조는 종족에 맞춰 재해석한다.

## 2. 삽화 제작 행렬 — 예외 없음
### 삽화 기준 종족형 10종
1. 인간
2. 엘프
3. 여우 수인
4. 고양이 수인
5. 개 수인
6. 늑대 수인
7. 새 수인
8. 설인
9. 인어족
10. 용족

### 직업 상태 34종
- 기본 7종: 전사 / 궁수 / 도적 / 성직자 / 마법사 / 무희 / 용왕
- 일반 심화 23종: 대검전사 / 창술사 / 검술사 / 쌍검술사 / 배틀슈터 / 스나이퍼 / 실프 / 아처 / 듀얼블레이드 / 암살자 / 씨프 / 사제 / 수도사 / 힐러 / 홀리나이트 / 아케인 메이지 / 마법검사 / 위자드 / 크로우 / 서큐버스 / 검무희 / 댄서 / 변기
- 용족계 심화 4종: 업화의 비룡 / 천수의 사룡 / 뇌명의 천룡 / 서리의 한룡

**총 10 × 34 = 340장.**

게임 규칙상 선택할 수 없는 조합도 삽화에서는 제외하지 않는다. 예: 인간 용왕, 용족 전사, 엘프 업화의 비룡 등도 모두 1장씩 제작한다. 이 자산은 향후 NPC/도감/확장 규칙에도 재사용할 수 있다.

## 3. 종족별 디자인 언어
- 인간: 가장 정석적인 기준형. 직업 장비의 표준 실루엣.
- 엘프: 길고 가는 비율, 긴 귀, 유기적인 금속 곡선, 식물·바람·마력 문양.
- 여우 수인: 긴 귀와 큰 꼬리를 의상 구성에 적극 사용. 교란·마법 직업은 부적/리본과 궁합을 강조.
- 고양이 수인: 가벼운 체형, 균형감과 점프 동작, 발목·손목 장비를 가볍게 분할.
- 개 수인: 안정적이고 활동적인 실루엣. 가죽·금속 조합, 실용적인 장비 구조.
- 늑대 수인: 길고 공격적인 실루엣, 털과 거친 금속, 전열 직업에서 육중함 강화.
- 새 수인: 실제 날개와 깃털을 반드시 실루엣에 포함. 등 장비가 날개를 가리지 않도록 설계.
- 설인: 흰 머리, 굽은 뿔, 두꺼운 체격, 털·뼈·냉기 결정·보온 구조.
- 인어족: 비늘, 뿔, 꼬리, 진주/산호/젖은 금속/반투명 막. 모든 직업을 물속성화하지 않는다.
- 용족: 큰 용각, 비늘, 꼬리, 실제 비행용 날개. 왕실/신전 계열의 고귀한 재질과 영물의 광륜.

## 4. 직업 계열별 실루엣 언어
- 전사계: 묵직한 대각선 무기, 넓은 어깨/갑주, 적색·철색·황금.
- 궁수계: 긴 수평/대각선 실루엣, 가벼운 장비, 녹색·청록·백색.
- 도적계: 비대칭, 짧은 날붙이, 망토/끈/그림자, 흑색·자주·적색.
- 성직자계: 수직선, 광륜, 성물, 백색·금색·옅은 청색.
- 마법사계: 원형 마법진, 부유체, 오브, 남색·보라·청록.
- 무희계: 리본/천/곡선, 팔과 허리의 큰 동작, 분홍·보라·검정·금색.
- 용왕/용족 심화계: 뿔과 날개가 왕관/망토를 대신하는 거대한 용형 실루엣.

## 5. 용왕 및 용족 심화 4종
### 용왕
- 아직 『용제』 현현 이전의 통제된 왕권 단계.
- 신성한 용각, 정돈된 부분 용린, 접힌 날개, 황금/백색/짙은 남색.
- 포즈는 위압적이되 광폭하지 않음. ‘수호신이자 왕’이 핵심.

### 업화의 비룡
- 불 / 공격 누적형.
- 검붉은 용린 + 황금 균열 + 주황 업화. 몸 앞쪽으로 쏠리는 공격적 대각선 포즈.
- 불꽃이 뿔과 날개 끝에 축적되는 시각 언어. 용제 현현 직전의 과열을 암시.

### 천수의 사룡
- 풀·생명 / 회복형.
- 녹색·청록·백색. 물의 고리와 살아 움직이는 덩굴/잎이 하나의 장식 언어를 이룸.
- 방어적이고 부드러운 S자 실루엣. 생명을 ‘쏟는’ 손동작과 긴 천/수류.

### 뇌명의 천룡
- 번개 / 추가 공격·치명타형.
- 백금·금색·보라. 날개와 번개가 여러 개의 잔상을 만들어 빠른 실루엣.
- 발이 지면에서 살짝 떨어진 공중 포즈. 무기보다 발톱/뇌광/궤적이 주역.

### 서리의 한룡
- 얼음 / 피격·보호막형.
- 백색·빙청·은색. 두꺼운 용린과 결정층이 성벽처럼 겹쳐짐.
- 네 계통 중 가장 넓고 안정적인 삼각형 실루엣. 날개는 방패처럼 앞으로 굽혀도 됨.

## 6. 『용제』 현현 시각 규칙
『용제』는 별도의 직업명이 아니라 네 심화 계통의 전투 변신 폼이다.
- 직업 선택 삽화 340장에는 기본적으로 ‘현현 전’ 모습을 사용한다.
- 각 용족계 심화 삽화에는 뿔/날개/광륜/속성 자원에 ‘곧 현현할 것 같은’ 징후를 넣어 변신 정체성을 암시한다.
- 향후 전투용 폼 전환 삽화를 따로 만들 경우 4계통의 용제 형태는 속성색과 용형 광륜이 크게 확장되고, 신체 주변에 계통별 용의 거대 잔상이 나타나는 방향으로 통일한다.
