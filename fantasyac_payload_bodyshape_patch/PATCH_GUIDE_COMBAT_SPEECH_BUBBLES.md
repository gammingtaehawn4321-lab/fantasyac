# 판타지악 — 전투 카드 말풍선 패치

## 추가 파일

- `src/data/combatSpeechReferences.ts`
  - 모든 말풍선 원문과 참조 키 원본
  - 여성 고성욕/무희 성인/무희 세트 사용자 작성 빈 영역 포함
- `src/combat/combatSpeech.ts`
  - HP 구간, 성별, 전직, 종족, 세트, 성인 변형 조건 해석기
- `COMBAT_SPEECH_REFERENCE.md`
  - 사용자가 문구를 수정하기 위한 참조 설명서

## 전투 Actor 변경

`BattleActor.speechProfile`을 추가했다.

- gender
- race
- beastkinType
- combatClass
- physicalAge

플레이어와 동료 생성 시 원본 캐릭터 정보를 복사하고, 적은 기본적으로 `MONSTER / UNKNOWN / NONE`을 사용한다. 적 팩토리에서 gender/race/combatClass를 명시하면 해당 값도 사용할 수 있다.

## 말풍선 표시

`ActorCard` 위에 작은 말풍선을 추가했다. 말풍선은 카드 모션과 독립적으로 표시되므로 근접 돌격/원거리 후퇴/마법 진동/피격 반동 중에도 유지된다.

참조 조건은 전투 시작, HP 4구간, 공격 성공/치명/실패, 회피, 피격/강피격, 방어 성공, 방어/지원/아이템, 처치/아군 전투불능, 승패, 도주까지 분리했다.

## 세트 대사

활성 세트 trait(`SET_*_2/3/4`)를 읽어 가장 강한 활성 세트를 판정한다. 세트 참조에 해당 이벤트 문구가 있으면 일반 대사보다 우선한다.

무희 4세트의 참조 칸은 사용자가 직접 작성할 예정이므로 전부 비워 두었다.

## 성인 상태 관련 안전장치

여성 고성욕/무희 성인 변형은 기존 `adultEquipmentContext`가 존재하는 경우에만 후보가 된다. 즉 기존 전투 Actor 생성 안전장치와 동일하게 성인 캐릭터 컨텍스트에서만 접근한다.

현재 사용자 작성 참조 문자열은 모두 빈 값이므로 해당 조건에서도 정상 전투 대사로 폴백한다.

## 검증

- 말풍선 참조 이벤트: 23종
- 세트 참조: 24/24
- 정상 세트 참조: 20/20 문구 존재
- 무희 세트 참조: 4/4 전 조건 빈 값
- 여성 고성욕 참조: 전 조건 빈 값
- 무희 성인 변형 참조: 전 조건 빈 값
- 성별+전직 + 종족 조합 resolver 확인
- 활성 세트 우선 참조 확인
- HP HIGH/MID/LOW/CRITICAL 구간 확인
- 적 BOSS 전용 참조 확인
- 신규 핵심 TypeScript 모듈 독립 typecheck 통과
- 전체 프로젝트 typecheck에서 신규 코드 관련 오류 없음. 의존성 미설치로 인한 React/Node 모듈 오류만 기존과 동일하게 남음.
